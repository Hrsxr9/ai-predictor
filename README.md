# AI Price Predictor

Sistem Prediksi Harga Barang Berdasarkan Data Historis.

Proyek mata kuliah Kecerdasan Buatan berbasis Python dan machine learning yang berjalan secara lokal tanpa API eksternal.

## Jalankan

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Lihat `PRESENTASI.md` untuk penjelasan konsep dan alur sistem.
